# Stacks (presets)

Os presets de fábrica vivem em um só lugar, empacotados com o motor:
[`packages/dengcode-engine/src/dengcode_engine/stacks/`](../packages/dengcode-engine/src/dengcode_engine/stacks/).

Assim quem instala pelo PyPI, executável ou extensão recebe os mesmos arquivos.
Stacks próprias ficam em `~/.dengcode/stacks/` (usuário) ou
`<projeto>/.dengcode/stacks/` (projeto). Veja `docs/especificacoes/stacks.md`.
